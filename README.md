# claudvideo

Генератор вертикальных видео (Shorts / Reels / TikTok) в формате **«интересный факт + анимированная схема»**.

```
тема ──► Claude пишет сценарий и рисует схемы (SVG) ──► нейроголос читает реплики
     ──► Chromium анимирует схемы по ходу речи ──► ffmpeg собирает mp4 1080×1920
```

Схемы рисует не генератор картинок, а Claude: каждая сцена это SVG, размеченный атрибутами анимации.
Поэтому стиль всегда единый и схематичный, подписи читаются, а ключ нужен только один (Anthropic).
Озвучка бесплатная (edge-tts, нейроголоса Microsoft).

## Что нужно

- Python 3.10+
- [ffmpeg](https://ffmpeg.org/) (команда `ffmpeg` и `ffprobe` в PATH)
- Ключ Anthropic API: `export ANTHROPIC_API_KEY=...`
- Chromium для рендера (ставится одной командой ниже)
- Для движка HyperFrames: [Node.js](https://nodejs.org/) 22+ (команда `npx`). Без него видео соберёт встроенный движок

## Установка

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium
```

Если Chromium уже стоит в системе, можно не качать второй: укажите путь в `CLAUDVIDEO_CHROMIUM`.

## Быстрый старт

```bash
python -m claudvideo make "Почему у осьминога три сердца" --preview
```

В `out/<дата>-<тема>/` появятся:

| Файл | Что это |
|---|---|
| `video.mp4` | готовый ролик 1080×1920, 30 fps |
| `script.json` | сценарий: реплики, SVG сцен, название, описание, теги, `fact_check` |
| `preview/scene_NN.png` | стоп-кадр каждой сцены (с `--preview`) |
| `audio/` | кэш озвучки |

После генерации в консоль печатаются название, описание и теги для YouTube, а также список **утверждений, которые нужно проверить по источникам перед публикацией**. Модель может ошибаться в фактах, это ваша ответственность как автора.

Готовые сценарии без ключа и без сети (папка `examples/`): `octopus` (три сердца осьминога), `venus` (на Венере сутки длиннее года), `saturn` (Сатурн легче воды), `neutron_star` (ложка нейтронной звезды), `armillaria` (гриб-гигант из Орегона).

```bash
python -m claudvideo preview examples/saturn.json      # стоп-кадры за пару секунд
python -m claudvideo render examples/octopus.json --no-voice   # видео без голоса
python -m claudvideo render examples/octopus.json              # с озвучкой (нужен интернет)
```

## Рабочий процесс

Генерация сценария стоит денег, рендер нет, поэтому правьте руками и рендерьте заново:

```bash
python -m claudvideo script "тема" -o work/s.json     # 1. только сценарий
python -m claudvideo preview work/s.json              # 2. смотрим схемы (быстро, без голоса)
#   правим work/s.json: реплики, SVG, цвета
python -m claudvideo render work/s.json --preview     # 3. финальное видео
```

Озвучка кэшируется по тексту, голосу и скорости: после правки одной сцены пересинтезируются только изменённые реплики.

## Команды и параметры

| Команда | Что делает |
|---|---|
| `make "тема"` | тема → сценарий → озвучка → видео |
| `script "тема"` | только `script.json` |
| `render script.json` | `script.json` → видео |
| `preview script.json` | `script.json` → стоп-кадры сцен, без озвучки и ffmpeg |

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--duration N` | 40 | целевая длительность, секунд |
| `--model` | `claude-opus-5-5` | модель; дешевле: `claude-sonnet-5-5` |
| `--effort` | `medium` | глубина «раздумий» модели: `low`…`max` |
| `--voice` | `ru-RU-DmitryNeural` | голос edge-tts (женский: `ru-RU-SvetlanaNeural`) |
| `--rate` | `+0%` | скорость речи, например `+10%` |
| `--no-voice` | выкл. | тишина, длительность оценивается по тексту |
| `--music файл` | нет | фоновая музыка, зацикливается; громкость `--music-gain` (0.12) |
| `--fps` | 30 | частота кадров |
| `--engine` | `auto` | движок видео: `hyperframes`, `builtin`; `auto` берёт HyperFrames, если есть `npx` |
| `--no-lint` | выкл. | не проверять вёрстку в браузере |
| `-o папка` | `out/...` | куда класть результат |

Список голосов: `edge-tts --list-voices | grep ru-RU`.

## Как это устроено

1. **Сценарий.** Claude получает тему и подробный гайд (текст для озвучки, палитра, правила вёрстки, разметка анимации) и возвращает JSON по жёсткой схеме (`models.py`): реплики и SVG каждой сцены.
2. **Автоконтроль.** SVG проверяется статически (`svgcheck.py`: viewBox, запрещённые элементы, номера реплик) и **в настоящем браузере** (текст не выходит за кадр, не перекрывается, не мельче 34 px). Найденные проблемы уходят обратно Claude на исправление, до двух раундов.
3. **Озвучка.** Каждая реплика синтезируется отдельно, так известно, когда именно она звучит. Границы слов от TTS используются для подсветки текущего слова в субтитрах; если их нет, слова раскладываются по длительности пропорционально.
4. **Анимация.** Все сцены лежат в одной HTML-странице; функция `seek(t)` ставит кадр на любой момент времени (детерминированно). Элемент с `data-beat="N"` появляется, когда диктор начинает реплику N.
5. **Сборка.** Скриншоты кадров идут прямо в ffmpeg вместе со звуковой дорожкой (голос по таймлайну + музыка).

### Два движка видео

| | `hyperframes` (по умолчанию при наличии Node.js) | `builtin` |
|---|---|---|
| Анимация | GSAP-таймлайн: упругие и мягкие кривые, смена сцен со сдвигом, всплывающие субтитры, плавно движущаяся сетка фона | собственный JS, простые кривые |
| Рендер | CLI [HyperFrames](https://github.com/heygen-com/hyperframes), версия зафиксирована в `hyperframes.py` | Playwright + ffmpeg |
| Нужно | Node.js 22+ | только Python |

Движок HyperFrames оставляет в папке результата проект `hyperframes/` (`index.html`, `gsap.min.js`, `voice.wav`). Его можно открыть в редакторе и поправить руками:

```bash
cd out/<папка>/hyperframes
npx hyperframes preview   # Studio в браузере: таймлайн, дорожки, правка
npx hyperframes render -o ../video.mp4
```

Разметка сцен у обоих движков одна и та же, сценарии менять не нужно. Превью сцен (`preview`) и проверка вёрстки всегда идут встроенным движком: это быстро.

### Разметка анимации в SVG

| Атрибут | Значения | Смысл |
|---|---|---|
| `data-beat` | `0`, `1`, … | появиться, когда начинается реплика с этим номером в сцене. Без атрибута элемент виден с начала сцены |
| `data-anim` | `pop` `slide` `fade` `draw` | способ появления. `draw` прорисовывает линию (path/line/circle/rect со stroke) |
| `data-delay` | секунды | дополнительная задержка, чтобы элементы одной реплики шли по очереди |
| `data-loop` | `pulse` `float` `spin` `wiggle` `flow` | постоянное оживление; `flow` двигает пунктир вдоль линии |

Холст сцены 1080×1150; плашка с названием сверху и субтитры снизу рисуются рендерером. Нижние ~300 px кадра оставлены свободными: там интерфейс платформ.

## Плагины и скиллы Claude Code

Проект подключает к Claude Code набор плагинов для видео, анимации и дизайна. При первом открытии папки в Claude Code он предложит доверять проекту и установить плагины: соглашайтесь.

| Что | Откуда | Зачем |
|---|---|---|
| HyperFrames | `hyperframes@claude-plugins-official` (heygen-com/hyperframes) | видео из HTML/CSS/JS, рендер в mp4 |
| Remotion | `.claude/skills/remotion-*` (remotion-dev/skills) | программные видео на React: анимации, субтитры, рендер |
| Скиллы Эмиля Ковальски | `.claude/skills/animate`, `improve-animations`, … (emilkowalski/skills) | правильные кривые и тайминги анимаций |
| taste-skill | `taste-skill@taste-skill` (Leonxlnx/taste-skill) | вкус и арт-дирекшн |
| impeccable | `impeccable@impeccable` (pbakaus/impeccable) | полировка интерфейса, `/impeccable …` |
| frontend-design | `frontend-design@claude-plugins-official` | дизайн фронтенда без шаблонности |
| UI UX Pro Max | `ui-ux-pro-max@ui-ux-pro-max-skill` | палитры, шрифты, стили |

Плагины объявлены в `.claude/settings.json`. Скиллы Remotion и Ковальски лежат в `.claude/skills/`, версии зафиксированы в `skills-lock.json`. Обновить их: `npx skills update -p`.

```bash
python -m pytest
```

Тесты рендера требуют Chromium и ffmpeg (иначе пропускаются). Обращения к Claude и edge-tts в тестах подменены.

## Что проверено, а что нет

Проверено: рендер примера в Chromium и сборка mp4 через ffmpeg (вертикальное видео, звук, анимация по репликам), статические проверки и проверка вёрстки, сборка звуковой дорожки, логика исправления сцен (с подменённым клиентом), схемы структурированного вывода.

Не проверялось вживую (в среде разработки не было ключа Anthropic и доступа к серверам озвучки): настоящий вызов Claude и настоящий синтез edge-tts. Если при первом запуске что-то из этого поведёт себя иначе, самые вероятные места: `scriptgen.py` (параметры вызова API) и `tts.py` (формат событий границ слов). Качество SVG от модели зависит от темы, поэтому смотрите `preview` до рендера.

## Структура

```
claudvideo/
  cli.py        команды make / script / render / preview
  scriptgen.py  Claude: сценарий и автоисправление
  prompts.py    системный промпт с гайдом по схемам
  svgcheck.py   статическая проверка SVG
  tts.py        озвучка edge-tts, кэш, границы слов
  timeline.py   тайминги реплик, слов, сцен
  audio.py      сведение дорожки (голос + музыка)
  render.py     встроенный движок: Playwright → кадры → ffmpeg
  frame.html    шаблон кадра встроенного движка
  hyperframes.py  движок HyperFrames: сборка проекта и рендер через CLI
  hf_frame.html   шаблон композиции HyperFrames (GSAP-таймлайн)
  vendor/gsap.min.js  GSAP 3.14.2, лицензия gsap.com/standard-license
examples/octopus.json   готовый пример сценария
tests/
```
